装机研究所 AI 助手

功能
1. 前台“聊聊用途，让配置更合适”填写用途、预算、是否包含外设，生成推荐方案。
2. 查看推荐型号、价格、取舍与升级建议，点击“一键应用这套方案”。
3. 在原有装机界面继续替换配件，点击“点评当前配置”重新分析。
4. 推荐方案应用前按数据库最新状态核价并检查基础兼容性。

首次配置
1. 启动 python run.py，在网站登录管理员。
2. 后台侧边栏点击“AI 服务配置”，或访问：
   http://127.0.0.1:8000/ai-settings.html
3. 填写提供 Chat Completions /chat/completions 和 JSON 输出的服务。
   服务基础地址填写 /chat/completions 前的完整前缀，模型填服务商提供的模型 ID。
   DeepSeek 的基础地址可填写 https://api.deepseek.com。
   其他兼容服务的地址、模型以服务商文档为准。
4. 填 API 密钥，勾选启用后保存，再点击“测试已保存的配置”。
   测试连接会发送一次简短模型请求。推荐和点评也会按服务商规则产生调用用量。
5. 普通用户登录后可以使用前台助手。

配置保存在后端 .local/ai-settings.json 中，已加入 .gitignore。
读取配置接口不返回密钥。修改配置时密钥留空会保留原密钥。
取消“启用 AI 助手”可以关闭功能。
部署或迁移时请妥善保存本机配置文件。
服务调用失败会显示原因；未配置模型时会提示管理员配置。
用途描述、预算、配件型号规格及选取的历史对话摘要会发送到管理员选择的 AI 服务。
每个账号在 PostgreSQL 中最多保留最近 150 轮成功的问答，推荐和点评共用额度。
每次请求参考最近 6 轮，以及最多 4 轮与当前问题关键词相关的较早记录。
继续调整推荐时，会以最近一套推荐的具体型号和要求为起点。可直接在预算与外设中覆盖上次设置。
开始全新方案时，取消勾选“接着上一套推荐调整”。
网站启动时会在现有数据库中自动创建对话表，部署账号需要有 riglab 架构的建表权限。
程序不会发送网站用户密码、数据库密码或登录会话。

技术
异步 FastAPI + Psycopg + httpx。新环境可运行：
python -m pip install -r requirements.txt
无需修改数据库表结构。

验证范围
服务接口、JSON 返回格式、预算、分类、已上架状态及基础兼容性会被程序校验。
性能点评是型号规格推断，最终表现需要按实际软件、分辨率和设置核实。
现有库没有完整的散热安装、机箱空间、BIOS 支持信息，需要购买前另行确认。
